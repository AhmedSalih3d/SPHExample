# Case 20 damping motion data

`CaseDampingPlane_PistonMovement.dat` is copied unchanged from the
DualSPHysics 5.4 distribution at
`examples/main/20_Damping/CaseDampingPlane_PistonMovement.dat`.
The plane case XML selects zero-based fields 0 (time) and 1 (piston x
displacement); the third column is not used. The file contains 361 samples
from 0 to 9 seconds at 0.025 second intervals.
