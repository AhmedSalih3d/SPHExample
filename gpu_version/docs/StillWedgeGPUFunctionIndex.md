# StillWedge companion: complete GPU package function index

Start with the [linear walkthrough](StillWedgeGPUWalkthrough.md) and [visual](StillWedgeGPUFlow.svg). This index accounts for **every explicit source function/method definition and subfunction in the GPU package**, not just exported entry points. It also includes local named functions, explicit anonymous callbacks, macros, type declarations (and therefore their implicit constructor families), and both StillWedge entry/helper scripts.

**Scope:** all 27 Julia files in `gpu_version/src`, plus the two directly relevant example files. The CPU package, unrelated example/benchmark/test programs, dependency internals and compiler-generated specializations are outside this GPU package source index. The precompilation workload is included for completeness, but is not an ordinary StillWedge time-step phase. In particular, this is a **source-definition inventory, not an assertion that all definitions execute in this example**. Active and inactive behavior is explained in the walkthrough.

Overloads and different local definitions have separate entries. Local callbacks show their lexical owner in the scope column. Anonymous functions introduced implicitly by comprehensions, generators, logging macros, keyword lowering or dependency macros are language/compiler machinery, not additional explicit package source functions. Source links lead to the definition; read its signature and nearby docstring for the precise overload. Type entries cover ordinary implicit constructors without attempting to list every instantiated parameter combination; the enum entry also accounts for its macro-generated constructor/helper family.

Generated by parsing the checked source with Julia `Meta.parseall`, including long-form methods, short-form assignments, nested definitions and explicit lambdas/do-blocks. There are **817 entries**. Numbering is a reading/index order, **not execution order**; steps 01-24 in the walkthrough provide execution order.
